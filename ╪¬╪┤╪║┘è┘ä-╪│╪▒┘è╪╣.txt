رصد سايبر — تشغيل سريع (نسخة جاهزة بالكامل)
=============================================

هذه الحزمة تحتوي كل شيء جاهزًا للتشغيل، بما في ذلك مجلد node_modules،
فلا تحتاج إنترنت أو تثبيت اعتماديات.

المتطلب الوحيد: Node.js الإصدار 18 أو أحدث.

خطوات التشغيل:
  1) فك ضغط الملف.
  2) افتح الطرفية داخل المجلد.
  3) شغّل:
       JWT_SECRET=ضع_سرًا_طويلًا_هنا  node backend/server.js
     (أو ببساطة: npm start — مع ضبط JWT_SECRET كمتغيّر بيئة)
  4) افتح المتصفح على:  http://localhost:3000

ملاحظات:
  - بدون قاعدة بيانات PostgreSQL، تعمل المنصة تلقائيًا بوضع «الذاكرة»
    (البيانات تُفقد عند إيقاف الخادم) — مناسب للتجربة.
  - للتشغيل الدائم مع حفظ البيانات: اضبط DATABASE_URL لقاعدة PostgreSQL
    وراجع ملف DEPLOY.md.
  - للتشغيل عبر Docker:  docker build -t rasd . ثم docker run.
  - اختبارات:  npm test

متغيّرات بيئة مهمة (انظر .env.example):
  JWT_SECRET      (إلزامي) سر توقيع الجلسات — اجعله طويلًا وعشوائيًا.
  PORT            منفذ الخادم (افتراضي 3000).
  SITE_URL        عنوان الموقع العام (للنشر).
  DATABASE_URL    رابط PostgreSQL (اختياري — بدونه يعمل بوضع الذاكرة).
  OPENAI_API_KEY  (اختياري) لتفعيل طبقة الخصم اللغوية.
